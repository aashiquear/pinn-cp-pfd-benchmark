# Citation key map -- PINNACLE benchmark study

Central bibliography: `references.bib` (184 entries, 183 carrying a DOI).

**Prose citation form used throughout this project:** `(author year significant_word)`, e.g.
(rezwan 2025 intragranular). The BibTeX key is the same three fields joined by hyphens, all
lowercase, first-author surname only: `rezwan-2025-intragranular`. Keys are unique and stable;
cite from this file rather than minting new keys.

**Verification.** Every entry was checked against the Crossref REST API. 143 entries resolved
directly by DOI. 40 were matched on title instead, using token containment of the Crossref title in
the source string (minimum 0.85 across all 40); of those 40, 35 carried no DOI at all in the source
list and 5 carried a DOI that was OCR-damaged in the source PDF and did not resolve, so the DOI in
this file was recovered by title match rather than copied from the source. 1 entry has no Crossref
record at all and is unverified. 143 + 40 + 1 = 184. OpenAlex was not queried -- it requires
an API key on every request and Crossref alone was sufficient.
